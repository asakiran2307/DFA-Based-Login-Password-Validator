Q
FINITE STATES

State representation

Each state combines a length counter capped at 8 with a four-bit mask. The mask records whether lowercase, uppercase, digits, and special characters have appeared.

δ
TRANSITION FUNCTION

Deterministic movement

For every character, the machine follows one defined transition: increase the capped length and add the character's class bit to the mask. The same state and input always produce the same next state.

F
ACCEPTING CONDITION

Reach the final state

The input is accepted when the length counter reaches 8 and the mask is 1111. Otherwise, the final state is non-accepting.
